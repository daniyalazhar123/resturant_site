# Design Reference - Luxury Restaurant UI

## Inspiration
- **Noma (Copenhagen)** - Minimalist, nature-inspired, story-driven. Clean typography, generous whitespace.
- **Eleven Madison Park (NYC)** - Refined dark aesthetic, gold accents, exceptional service UX.
- **Le Bernardin (NYC)** - Elegant, maritime luxury, sophisticated.
- **Alain Ducasse at The Dorchester (London)** - Opulent but restrained.

## Current Design Analysis (L'Étoile Dorée)
**Strengths:**
- Dark theme (zinc-950) with amber/gold accents - appropriate for luxury
- Serif fonts for headings (elegant)
- Good use of imagery
- Sophisticated color palette

**Weaknesses:**
- Can feel templated
- Some generic UI elements
- Needs more restraint and breathing room
- Could benefit from more custom details

## Luxury Design Principles
1. **Restraint over decoration** - Every element must earn its place
2. **Typography hierarchy** - Use display serif sparingly, body text refined
3. **Generous whitespace** - Luxurious feels spacious
4. **Subtle motion** - Framer Motion used but can be refined
5. **Quality imagery** - High-end food photography essential
6. **Gold accents** - Use as highlights, not everywhere
7. **Dark mode done right** - Rich blacks, not pure black
8. **Micro-details** - Custom borders, gradients used subtly

## Recommendations
- Move away from "template-y" sections
- Add more editorial feel (asymmetry, large type)
- Refine hover states
- Better use of negative space
- Consider adding texture/subtle noise
- Improve mobile experience
- Add custom cursor? Maybe overkill
- Focus on storytelling
